# Writing and annotation discipline

## Decide where a sentence belongs

Point to the object that would become hard to read if the sentence disappeared. A short label earns space when it changes which interval, branch, comparison or unit a viewer identifies. Use the following routing test on slide shapes, SVG text, images of older charts, and the area beneath every figure.

| Material | Destination | Example |
|---|---|---|
| A variable, unit, interval, branch name, scale endpoint or uncertainty convention | At the relevant mark or axis | “Buildup ≈1,059–1,433”, “Latency (s/sample)”, “mean ± SD” |
| A qualifier that changes the comparison or denominator | In the header, legend or nearby main text | “Among valid parses” |
| A sentence that answers the slide's question | Main reading area at normal body size, if the title and data leave the conclusion open | “GroundingMOMENT gives up 4.4 event mAP points and reduces latency from 49.0 to 1.2 seconds per sample.” |
| Two distinct facts a reader must extract from a paired example | Place each label by the geometry it explains | In the elasticity figure, upper captions name the phase balance. Lower spans identify the total event length. |
| The subject of an upcoming section | A short line under the divider title when the audience needs orientation | Name the research topic in the same terms and order as the following pages. |
| Provenance | Compact formal citation in the footer, with a full reference or locator in notes or references | “Hou et al. (2026), Table 2 and Appendix D.” |
| A supporting configuration or longer explanation | Speaker notes, unless it changes the visible finding | Describe the two inference backends when discussing latency. |
| An instruction to the author or a pending design choice | Reviewer thread or private revision list | “Move the event span above the trace.” |
| A sentence the visual already says, or narration of the drawing process | Delete from every audience-visible layer | A chart with a labeled latency column needs no gray sentence saying that the column shows latency. |

A necessary inference deserves a legible sentence. A source citation deserves attribution. Neither belongs in a tiny gray commentary strip. Recheck the actual SVG or bitmap after deleting a slide textbox. A copy baked into the artwork will survive the edit.

## Write for the ear

Use an actor, a concrete verb and a scientific object. Read the words against the figure as if presenting. Explain what “while” requires two channels to do at the same time. Keep the query intact when quoting it. Highlight only the phrases whose correspondence the audience should follow. Keep method names, operator names, units and the author's precise choice of verb.

Prefer “The detector returns a start and end time for each matching event” to an abstract claim about enhanced perception. In a comparison, say which score changes, by how much and in which setting. In a proposal, write “We propose training a single-pass detector on traces with labeled event boundaries.” Keep uncertainty where evidence requires it, such as an approximate breakpoint or a conditional score. Cut reassurance, generic importance claims, slide narration and repeated qualifications.

## Review English separately from the science

Read each slide once for argument and once for spoken English. Check subject–verb agreement, antecedents, parallel comparisons, number and unit. Recalculate the arithmetic after rewriting a finding. Run the same pass on diagram labels and headers. For a wording-only review, preserve numbers, methods, author's voice and all unrelated design.
